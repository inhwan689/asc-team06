# ASC 팀 프로젝트 team06

eBPF verifier 취약점 4건(CVE-2023-39191, CVE-2021-33624, CVE-2023-2163, CVE-2021-31829) 분석 저장소.

## 폴더 구조
회차/이름_CVE 순서로 올린다.

- 2회차/김인환_CVE-2023-39191 — 패치 직전 커널(6.2.0-rc2) 빌드, QEMU 부팅, dynptr BPF 로드 확인
- 2회차/김홍균_CVE-2021-33624 — 패치 직전 커널(5.13.0-rc3+) 빌드, QEMU(TCG·KVM) 부팅, BPF 로드 확인
- 2회차/안시후_CVE-2021-31829 — 패치 직전 커널(5.12.0) 빌드, QEMU(KVM, -cpu host) 부팅, BPF 로드 확인(root·비특권)

## 올리지 않는 파일
커널 이미지(bzImage)와 initramfs(*.cpio.gz)는 올리지 않는다. 각 폴더의 스크립트로 다시 만들 수 있다.
